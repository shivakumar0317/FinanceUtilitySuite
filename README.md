# Finance Utility Suite

A professional desktop application for financial analysis.

## Features

- Stock Analyzer
- Risk Analysis
- Beta Calculation
- Excel Report Generation
- Dashboard
- Live Progress
- Background Processing

## Technologies

- Python
- CustomTkinter
- Pandas
- OpenPyXL
- Yahoo Finance
