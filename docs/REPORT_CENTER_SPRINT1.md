# Report Center – Sprint 1

## Included

- Registry-driven report catalog
- Immutable `ReportDefinition` metadata
- Duplicate-safe `ReportRegistry`
- Searchable Report Center page
- Reusable `ReportCard` widget
- Sidebar and dashboard navigation integration
- Available and Coming Soon report states

## Current reports

Available: Portfolio, Analytics, Client Holdings.

Coming soon: MTF Risk and Risk Analytics.

## Integration

The package follows the current desktop layout and adds `desktop/reports_page.py` rather than restructuring existing pages.

Sprint 2 will connect the Generate action to reusable data-selection, save, progress, completion and error dialogs.
